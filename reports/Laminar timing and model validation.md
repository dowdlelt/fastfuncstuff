# TR spaced TENT needs matching laminar predictions

**TENT can fit fractional event onsets with knots spaced one TR apart, without upsampling the acquired data.** Arbitrary onset placement does not, however, guarantee that every knot is identifiable or that its fitted coefficient equals the physical HRF at that lag. The current `ffs_laminar` adapter assumes the latter, so the complete chain is not yet validated for arbitrary schedules. The appropriate correction retains TR-spaced knots: pass each physiological prediction through the same event schedule and deconvolution estimator used for the data, then use the corresponding uncertainty. Controlled experiments support this correction. This review also fixed a real timing-precision bug and an unequal-window profile-reporting bug; neither fix alone resolves the observation-model mismatch.

**The scientific target is better known-truth HRF and neuronal-layer recovery than reference methods, not merely AFNI agreement.** Matching AFNI checks the implemented basis convention. It does not resolve degenerate mixed-onset designs or establish accurate physical curves. The independent truth experiments below, followed by full laminar recovery and null calibration, are the relevant acceptance tests.

Review date: 2026-11-10. Detailed measurements, sources and execution limits are in the [research notes](</home/logan/Dropbox/Resources/code/fastfuncstuff/research_notes/Laminar timing and model validation/>).

## Fractional onsets work, but timing controls what is observed

The sampling clock and the knot clock are different. With acquisition times `t_n = n·TR + t0`, event onset `o_j`, and a TR-spaced lag grid, TENT evaluates each triangular basis at the actual fractional lag `t_n − o_j`. It does not require rounding the onset, and fractional timing does not require sub-TR knots. If the underlying response lies in the fitted piecewise-linear basis and the joint design identifies its coefficients, ordinary least squares targets those coefficients correctly. If the response curves between knots, the coefficients generally describe its best design-dependent projection. Whitening and roughness penalties change that projection. This is a distinction between the model being fit and physical sample values, rather than a failure to evaluate fractional times. [AFNI TENT specification](https://afni.nimh.nih.gov/pub/dist/doc/program_help/3dDeconvolve.html), [implementation](</home/logan/Dropbox/Resources/code/fastfuncstuff/fastfuncstuff/design/matrices.py>).

For a single condition whose events share an off-grid phase away from the narrow endpoint extensions, the AFNI half-tent window convention can give fewer distinct observed lags than free knot coefficients. In the tested nine-knot design, phases 0.1, 0.3, 0.5 and 0.9 all had rank eight. Different phases can restore rank, but closely clustered phases can still amplify noise severely. These checks must use the actual joint task design after nuisance projection: pooled phase diversity can hide an individual condition's deficiency. Known invertible AR whitening preserved the rank deficiency in the tested two-condition example. [Timing audit and numeric results](</home/logan/Dropbox/Resources/code/fastfuncstuff/research_notes/Laminar timing and model validation/tr_knots_audit.json>).

The specific window `-window 0.9285 15.7845` at TR=1.857 contains nine knots spaced exactly one TR apart. When every onset is half-TR from acquisition, these knots land on the observed event-relative lags and TENT becomes an exact FIR at those lags. That alignment is a valid special case. It does not align mixed on-TR and half-TR events simultaneously, and it is not a universal solution for arbitrary phases. No single onset-independent grid can place a knot at every lag in a mixed schedule while retaining only TR spacing.

The new CPU audit used three 240-volume runs, 32 events per run, nine TR-spaced knots, independent analytic HRFs with different depth amplitudes and timing, white noise SD 0.15, and 128 noise draws per depth. Truth tapered to zero by the window end, avoiding omitted-tail bias. RMSE below is against the known physical response at the knot times; it is **one controlled benchmark, not a universal ranking**. Singular OLS entries use a pseudoinverse and do not establish that the missing direction was measured. ## Global smoothing and the two REML choices have different roles

`ffs_reml` estimates acquired-series temporal noise and performs GLS. `-tent-smooth reml` chooses a roughness-penalty strength by restricted likelihood. `-tent-smooth global` chooses one strength by median leave-one-run-out prediction over selected signal voxels. These choices address noise or regularization; none creates observations in a missing design direction. Current shared model parsing supports TENTzero, so a general claim that REML cannot supply zero-constrained TENT curves is inaccurate. [Smoothing implementation](</home/logan/Dropbox/Resources/code/fastfuncstuff/fastfuncstuff/glm/smooth_basis.py>), [REML CLI](</home/logan/Dropbox/Resources/code/fastfuncstuff/fastfuncstuff/cli/reml.py>).

A shared penalty avoids deliberately giving every depth a different smoothing strength, which helps comparisons across depth-dependent SNR. However, global selection uses the data both to choose eligible voxels and to choose lambda. **Its application is linear only with the selected settings held fixed; the full adaptive procedure is not exactly linear.** For fixed settings, smoothing still changes the expected curve. For a misspecified coarse basis, GLS also changes the projection target and can move coefficients farther from literal HRF samples. REML is therefore usable, but its resulting operator and uncertainty must accompany the curves. Cross-fitting or simulation is needed to account for adaptive selection; treating the chosen lambda as externally fixed does not capture that uncertainty.

## Matching the estimator removes a demonstrated laminar bias

The current curve handoff contains values, times, depth coverage and PSF information, but lacks the event schedule, full task/nuisance design, deconvolution operator and coefficient covariance. `two_condition_batch` simulates isolated events and the inversion compares model samples directly with curve coefficients. That is the central unresolved mismatch. [Adapter](</home/logan/Dropbox/Resources/code/fastfuncstuff/fastfuncstuff/laminar/io.py>), [inversion](</home/logan/Dropbox/Resources/code/fastfuncstuff/fastfuncstuff/laminar/inversion.py>).

Let `W` whiten acquired noise, `N` be nuisance, `M` remove `WN`, `Xw=WX`, and `P` be the penalty. For fixed settings, write the fitted coefficients as

```text
L = (Xwᵀ M Xw + λP)⁺ Xwᵀ M W
β̂ = L y
model prediction in coefficient space = L gθ(actual event schedule)
fixed-settings coefficient covariance = L Σ Lᵀ
```

The pseudoinverse notation covers supported singular cases; the likelihood must operate on the supported subspace. `gθ` predicts acquired samples, so **no acquired-data upsampling is required**. All conditions must pass through the same joint estimator to preserve overlap and cross-condition effects. For isolated-response superposition, the prediction can be formed from the continuous HRFs at the actual event-relative lags. For rapid nonlinear designs, the full input train must drive the physiological model before applying `L`. These are different assumptions, and the experiment below tested only the former.

A new noise-free experiment used TR=2 s, **17 knots spaced exactly 2 s over 0–32 s**, 95 events, seven vascular depths and Legendre nuisance. Fine physiological truth was sampled at actual acquisition lags. Only sigma varied in recovery; its generating value was 3 Hz and all other parameters were known. Comparing coefficients with raw model samples yielded sigma estimates of **2.715–3.316 Hz** across timing and penalty cases. Applying the same estimator to each prediction recovered **3.000 Hz in every case**, including singular half-TR timing. The fixed diff2 penalty had relative lambda 1; it was not a globally selected lambda. This establishes the observation correction under controlled assumptions, not full DCM identifiability or calibration. [Experiment](</home/logan/Dropbox/Resources/code/fastfuncstuff/scripts/laminar_curve_review/observation_operator.py>), [numeric results](</home/logan/Dropbox/Resources/code/fastfuncstuff/research_notes/Laminar timing and model validation/observation_operator.jsonl>).

Even white acquired noise produced maximum off-diagonal coefficient correlations of 0.445–0.809 for OLS and 0.818–0.862 for the fixed penalty. Production inversion currently uses identity temporal precision within each depth. Consequently, raw free energies and layer probabilities do not yet incorporate deconvolution uncertainty. Changing knot count, smoothing or effective rank can change apparent evidence without adding information. Depth-grid fits also reuse the same voxels; summing their free energies would not create independent evidence. Full calibration must rerun adaptive deconvolution and model selection under realistic, run-preserving noise/null simulations.

## The vascular equations pass independent checks

All five distinct requested papers are present in the wiki; duplicate 2021 filenames represent the same work. The relevant references are the [2015 neuronal model](</home/logan/Dropbox/Resources/code/fmri_wiki/raw_sources/havlicek_et_al._2015_Neuroimagephysiologically_informed_dynamic_causal_modeling_of_fmri_data.pdf>), [2020 vascular model](https://doi.org/10.1016/j.neuroimage.2019.116209), [2021 inversion study](https://doi.org/10.1016/j.pneurobio.2021.102055), [2018 physiology review](https://doi.org/10.1016/j.neuroimage.2017.02.063), and [Faes 2026](https://www.nature.com/articles/s41467-026-73540-z). Both the [original Havlicek repository](https://github.com/martinhavlicek/laminar_BOLD_model) and [Faes reference repository](https://github.com/lonikefaes/predictive_tones) were verified.

The forward chain is neuronal excitation/adaptation, feedforward neurovascular coupling and flow, local microvascular volume/deoxyhemoglobin, then serial ascending-vein transport toward the surface. The BOLD observation equation combines these compartments, followed by depth mixing/PSF. The model therefore separates local neuronal drive from superficial vascular accumulation through constrained dynamics. It does not derive an unconstrained neuronal signal directly from each observed HRF. Three neuronal depths and more vascular depths are distinct model resolutions, unrelated to the temporal knot spacing.

Fresh execution passed 12 forward-model tests against stored MATLAB equations and Jacobian oracles. Independent steady-state and random-state physical conservation checks across K=3,7,9,10,11 gave residuals **≤3.4e-15**, with resting BOLD exactly zero. A separate DOP853 comparison checked integration on one stable K=7 trajectory. At dt=0.05 s, maximum errors were 0.0760% of peak for reference-Jacobian integration and 0.0489% for exact-Jacobian integration. Halving dt improved RMS error 1.75-fold versus 4.03-fold. The preserved reference chain-rule quirk therefore changes convergence order, but its prediction effect was small in this trajectory; this does not bound extreme posterior states or evidence differences. A fresh MATLAB oracle generation was unsuccessful, and the older claim of 8e-15 parity with the separate original Havlicek simulator was not independently rerun. [Physiology audit](</home/logan/Dropbox/Resources/code/fastfuncstuff/scripts/laminar_curve_review/physiology_audit.py>), [integration audit](</home/logan/Dropbox/Resources/code/fastfuncstuff/scripts/laminar_curve_review/integration_audit.py>).

The supported physiology remains constrained. The BOLD constants are anchored to 7 T GE; changing B0 alone does not recalibrate all field-dependent constants. Baseline sigma increases self-inhibition, whereas positive diagonal modulation B reduces it; B is not raw neuronal amplitude. DCM here compares which modeled neuronal-depth connections change between conditions inside an ROI; it is not a separate spatial activation finder. The 2021 study supports condition differences and sensitivity analyses of vascular assumptions, including ascending-vein CBV slope. A correct draining model also does not eliminate remote pial-vein blooming or PSF uncertainty. Thus code parity supports the forward equations, while physiological assumptions and the observation model still determine whether inferred layer modulation is credible.

Commit `f06340fb` fixes the separate unequal-window bug: peak profiles and exports now follow each condition's fitted-row mask instead of using the first condition's length for both. ## The remaining implementation is a defined handoff

The next production change is to serialize the exact deconvolution operator or sufficient statistics and metadata, evaluate physiological predictions through it, and carry covariance on the estimable subspace. That handoff must retain sample timing, events/durations, censoring, preprocessing/scaling, nuisance, joint task design, basis boundaries, selected penalty/lambda and whitening. It must distinguish fixed-settings uncertainty from adaptive lambda/noise estimation. Then realistic simulations must test full layer-model recovery and false positives across onset mixtures, depth SNR, autocorrelation and rapid nonlinear input trains. **The demonstrator supports this route while preserving TR spacing; it is not yet wired into `ffs_laminar`.**

Acceptance should measure error against known HRF amplitudes, latency and depth ratios, with both on-TR and mid-TR events in each condition, lopsided mixtures, tightly clustered phases and arbitrary phases. Compare candidate estimators with OLS/GLS and existing regularizers at the same TR-spaced knots and noise draws. Require lower curve error without systematic depth bias, honest uncertainty/flags for unsupported combinations, and recovery of known modulation B and layer hypotheses in the complete estimator-aware DCM. Null simulations must repeat adaptive choices and check calibrated layer false positives. A method must not pass by predicting held-out acquired samples while silently inventing unobserved knot values, nor by matching AFNI while both miss the known truth.
