# Provenance and attribution

`fastfuncstuff` is licensed **GPL-2.0-or-later** (see `LICENSE`). This file records where
the code came from, because parts of it are derived from other people's work and the
licence obliges us to say so — and because knowing which parts are ports and which are
independent implementations is genuinely useful when reading the code.

Three different relationships to upstream projects appear below, and they carry very
different obligations:

1. **Invoking a binary.** Running another program is not creating a derivative work.
   `ffs_benchmark` shells out to `3dREMLfit`, `melodic`, `fast`, `3dvolreg` and others.
   This creates no obligation on this repository.
2. **Implementing a published method.** Copyright covers expression, not ideas or
   methods. Implementing an algorithm from its paper creates no obligation beyond
   citation, which we give.
3. **Porting from source.** This produces a derivative work and the upstream licence
   follows it. This is where the GPL obligation comes from.

## Called, not ported

- **warpkit** (MIT, © Andrew Van; https://github.com/vanandrew/warpkit) is a hard
  dependency of `processing/medic.py`, which calls its in-process ROMEO / MCPC-3D-S
  field-map estimation and does not reimplement it. What this repository owns on that
  path is the GPU warping and pipeline integration. MIT is GPL-compatible, so the
  combination is fine; the notice is retained here as MIT requires.
  Method: Van, Montez, Laumann et al. (2026), *Imaging Neuroscience*.

not permit us to grant. Copies obtained under MIT before that date remain under the terms
